Quick Inference — phone test suite (development only)

Runs the device test, then loads, checks and times each model on each engine, sending results to the Mac. Each model is deleted after its tests, and the test storage is wiped when the run ends. Leave this page open: the Mac can start new runs remotely. ?reset starts over, ?all adds models up to 4B, ?only=id,id picks models, ?clear wipes all test storage.
